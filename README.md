# 🛰️ EE351_Project

This project demonstrates how to use a GPS module with a Raspberry Pi.

---

## 🚀 Usage Guide

1. **Connect the GPS module** to the Raspberry Pi **before running any program**.

2. **Enable and start the GPS interface** by running:
   ```bash
   source venv/bin/activate
   ```
   ```bash
   sudo ./wheeltec_gps.sh
   ```
   Run the main program:
  
   ```bash
   python3 main.py
   ```
